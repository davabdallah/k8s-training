# Day 3 - Ingress, Probes, Storage, and Mini Project

Day 3 connects applications to HTTP traffic, adds health checks, introduces persistent storage, and finishes with a mini project.

## Learning Objectives

By the end of Day 3, students should be able to:

- Enable and use the Minikube Ingress addon.
- Create Ingress rules for HTTP routing.
- Add liveness and readiness probes to a Deployment.
- Create and mount a PersistentVolumeClaim.
- Build a small frontend/backend application using Kubernetes manifests.
- Validate and clean up a complete application stack.

## Agenda

Duration: 6 hours

| Time | Topic |
| --- | --- |
| 75 min | Ingress and local HTTP routing |
| 75 min | Liveness and readiness probes |
| 75 min | PVC storage |
| 120 min | Mini project implementation |
| 15 min | Final cleanup |
