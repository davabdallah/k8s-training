# Day 1 - Kubernetes Basics and Pods

Day 1 focuses on local cluster setup and the first Kubernetes object students usually work with: the Pod.

## Learning Objectives

By the end of Day 1, students should be able to:

- Start and verify a Minikube cluster.
- Use kubectl to inspect cluster resources.
- Create Pods using imperative commands.
- Create Pods using YAML manifests.
- Read Pod logs and Kubernetes events.
- Use labels, selectors, and namespaces.
- Clean up resources safely.
